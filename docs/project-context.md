# agifornormies

Teach core AGI concepts to non-technical people by walking one causal chain. Inspired by [nontechnical.dev](https://nontechnical.dev) craft, not its term list.

Li guides. Keep the map minimal. Build one block at a time.

## The chain

**data → learning → neural networks → language models → reasoning → memory → tools → agents → harnesses → senses → robotics → AGI**

Every next idea answers: **what problem did this solve?** A story people can reconstruct, not a vocabulary pile.

## Voice

This site explains the chain. Openings say what the thing is. They do not open on jobs, mood, or whether people should be excited.

College floor, then engineering detail, then named industry fact. Still no jargon. A sharp teenager can follow because the terms were unpacked, not because the prose was written down.

When work comes up, say replacement of workers, not cheaper, and say people can adapt. Do not lead with that, and do not leave it out when the idea implies it.

A new comment adds a constraint. It does not erase the last one. Full rules: `.cursor/rules/writing.mdc`.


## Acts (names only)

1. How machines learn — data, machine learning, neural nets
2. How we got ChatGPT — language as data, transformers, foundation models
3. From predicting words to thinking — post-training, reasoning
4. Intelligence starts doing things — memory, tools, agents
5. Why agents need infrastructure — harnesses
6. Digital to physical — senses, robotics
7. Then AGI — what would it actually mean?

## Each lesson (same five parts)

1. One-sentence definition
2. Why it was invented
3. One analogy
4. One real example
5. One question that proves you understand it

Reuse old vocabulary in later lessons. Show a **growing knowledge tree** so people can see where they are.

## Build order

One block at a time. First block: **Data.**
